# 📦 SupplyIQ — Power BI Supply Chain Analytics

![Banner](Images/banner.png)

### End-to-End Supply Chain Analytics Dashboard using SQL, Python & Power BI

An end-to-end Business Intelligence project built using **SQL, Python, Power BI, Power Query, and DAX** to analyze supply chain performance, logistics, inventory, supplier efficiency, and product segmentation.

# 📌 Project Overview

SupplyIQ is a complete Supply Chain Analytics solution designed to simulate a real-world retail supply chain.

The project demonstrates the complete analytics workflow:

- SQL Database Design
- Star Schema Data Modeling
- Data Cleaning
- Data Transformation using Power Query
- Data Analysis using DAX
- Product Segmentation using Python
- Interactive Power BI Dashboard

The dashboard enables business users to monitor inventory, logistics, suppliers, products, and overall supply chain performance.
